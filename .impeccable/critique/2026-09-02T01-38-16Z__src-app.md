## Priority Issues

**P0 — No feedback after visibility toggle**
Switch flips silently. If API fails, user sees momentary wrong state.
Fix: Add Sonner toast on success/failure.

**P1 — Dashboard empty state is a dead end**
"No repositories found." with zero recovery guidance.
Fix: Distinguish "no repos" from "no matches." Show reset link.

**P1 — Disabled Settings menu with no explanation**
Ghosted menu item. No tooltip. Feels broken.
Fix: Remove or add "Coming soon" tooltip.

**P2 — Login has no loading state during OAuth redirect**
No pending state after clicking sign-in.
Fix: Show spinner, disable button during redirect.

**P2 — Mobile toolbar stacking buries table**
Three rows of controls before table on mobile.
Fix: Collapse filters into single button on mobile.
